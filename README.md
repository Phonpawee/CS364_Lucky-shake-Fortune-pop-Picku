# Lucky Shake Fortune Pop Picku

**LuckyShake** แอป Android ช่วยตัดสินใจว่า **วันนี้กินอะไรดี** เขย่ามือถือเหมือนเขย่ากระบอกเซียมซี ไม้เซียมซีหล่นออกมาบอกเมนู พร้อมคำทำนายสนุก ๆ

โปรเจกต์รายวิชา CS364 การพัฒนาโปรแกรมประยุกต์สำหรับอุปกรณ์พกพา

## แอปทำอะไรได้

### เขย่าเพื่อสุ่มเมนู
- เขย่าเครื่อง แอปตรวจจับด้วย accelerometer แล้วสุ่มเมนูพร้อมคำทำนาย
- เขย่าครั้งเดียวไม่สุ่มซ้ำ (กันเขย่าซ้ำภายใน 1 วินาที)
- ผลมี 4 ระดับดวง (สัดส่วนเริ่มต้น 20 / 40 / 30 / 10) และเมนูที่ได้ล่าสุดจะมีโอกาสออกซ้ำลดลง
- ตัวกรอง: ประเภทอาหาร, ไม่เอาของทอด, ไม่เอาเผ็ด
- ขอเซียมซีใหม่ได้ตามโควตา (ค่าเริ่มต้น 3 ครั้ง ปรับ 1–5 ได้ในตั้งค่า)
- บันทึกผลเป็นรูป PNG

### โชคมีน้ำหนัก
- ตั้งน้ำหนักความชอบของแต่ละเมนูได้ 1–10 ในหน้าตั้งค่า (เริ่มที่ 5)
- เมนูที่น้ำหนักสูงมีโอกาสออกมากกว่า น้ำหนักค่อย ๆ กลับสู่ 5 สัปดาห์ละ 1 ขั้น

### เมนูของตัวเอง
- เพิ่ม แก้ไข ลบเมนู และจัดชุดเมนูของตัวเอง เก็บในฐานข้อมูลบนเครื่อง (SQLite) ไม่ต้องใช้อินเทอร์เน็ต

### โหมดกลุ่ม
- เพื่อนทั้งโต๊ะ 2–8 คน ผลัดกันเสนอกลุ่มอาหารหรือชื่อร้าน (คนละไม่เกิน 3 ร้าน) แล้วเขย่าสุ่มผู้ชนะ

### สมุดเซียมซี
- เก็บประวัติผลที่ได้ พร้อมสถิติ ลบทีละรายการหรือล้างทั้งหมด (ล้างทั้งหมดมีกล่องยืนยัน)

### การใช้งานทั่วไป
- หน้า Welcome ตอนเปิดแอปครั้งแรก
- แจ้งเตือนตามมื้ออาหาร
- ภาษาไทย / อังกฤษ
- ธีมสว่าง / มืด
- รองรับแนวนอนและหลายขนาดจอ (มือถือ แท็บเล็ต)
- หมุนจอหรือสลับแอปแล้วข้อมูลที่เลือกไว้ไม่หาย กด Back ขณะมีผลที่ยังไม่บันทึกจะมีกล่องยืนยันก่อนทิ้ง
- กด Back ที่หน้าหลักจะออกจากแอปทันที

## ติดตั้งและรัน

ต้องมี Android Studio และมือถือ Android 8.0 (API 26) ขึ้นไป หรือ emulator

```bash
git clone https://github.com/Phonpawee/CS364_Lucky-shake-Fortune-pop-Picku.git
cd CS364_Lucky-shake-Fortune-pop-Picku
```

เปิดโฟลเดอร์ใน Android Studio รอ Gradle sync แล้วกด Run บนมือถือจริง (เปิด USB debugging) หรือ emulator
เมื่อเขย่า ควรใช้มือถือจริงเพราะ emulator จำลอง accelerometer ได้จำกัด

## เทคโนโลยี
Java + XML Views · SQLite (`SQLiteOpenHelper`) · accelerometer (SensorManager) · Material Components · minSdk 26 (Android 8.0) · targetSdk 37

## โครงสร้างไฟล์

```
app/src/
├── main/
│   ├── AndroidManifest.xml
│   ├── java/com/cs364/luckyshake/
│   │   ├── MainActivity.java      หน้าหลัก เขย่าสุ่มเมนู
│   │   ├── data/                  ฐานข้อมูล SQLite, เมนู, ประวัติ
│   │   ├── logic/                 กติกาการสุ่ม, น้ำหนัก, โควตา
│   │   ├── sensor/                ตรวจจับการเขย่า
│   │   ├── fortune/               คำทำนาย
│   │   ├── reminder/              แจ้งเตือนตามมื้อ
│   │   └── ui/
│   │       ├── welcome/           หน้า Welcome
│   │       ├── home/              สถานะหน้าหลัก
│   │       ├── result/            หน้าผล, บันทึกรูป
│   │       ├── menu/              รายการเมนู, ฟอร์ม
│   │       ├── weights/           ตั้งน้ำหนักเมนู
│   │       ├── group/             โหมดกลุ่ม
│   │       ├── journal/           สมุดเซียมซี, สถิติ
│   │       ├── settings/          ตั้งค่า
│   │       └── nav/               ปุ่ม Back, แถบเมนูล่าง
│   └── res/
│       ├── layout/                หน้าจอ (แนวตั้ง)
│       ├── layout-land/           แนวนอน
│       ├── layout-sw600dp*/       แท็บเล็ต
│       ├── values/, values-th/    ข้อความอังกฤษ/ไทย, สี, สไตล์, ธีม
│       ├── values-night/          สีธีมมืด
│       └── drawable*/, mipmap-*/  ภาพประกอบ, ไอคอน
├── test/                          Unit test
└── androidTest/                   Instrumented test
```

ข้อความทั้งหมดอยู่ใน `strings.xml` ทั้ง `values` (อังกฤษ) และ `values-th` (ไทย) สีและสไตล์กลางของแอปอยู่ใน `values/colors.xml`, `values-night/colors.xml` และ theme `Theme.LuckyShake`
